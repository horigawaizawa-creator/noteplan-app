# Лок.Планувальник

Локальний застосунок для нотаток, планів, WBS-структур та проєктів. React + Vite, дані та файли зберігаються в IndexedDB вашого браузера.

## Мобільний і сенсорний досвід

Інтерфейс однаково зручний і на ПК, і на телефоні/планшеті:

- **Адаптивна верстка.** На екранах ширше ~900px — звичний триколонковий
  вигляд (як і раніше). Вужче — одна панель на екран (список документів /
  документ / чек-лист) з кнопками «← Назад» та швидким переходом до
  чек-листа з заголовка документа.
- **Реорганізація без перетягування.** Перетягування мишею лишилось для ПК,
  але тепер скрізь є рівноцінна альтернатива на дотик і з клавіатури:
  - кроки плану та блоки WBS — кнопки ▲/▼ прямо в рядку (раніше блоки WBS
    взагалі не можна було переупорядкувати);
  - документи в сайдбарі — кнопка «⋯» відкриває меню «Вище / Нижче /
    Перемістити в проєкт / На верхній рівень».
- **Без прихованих елементів.** Кнопки, які раніше з'являлись лише при
  наведенні миші (закріпити, видалити, дії WBS-блоку), тепер завжди хоч трохи
  видимі — на сенсорному екрані навести неможливо.
- **Більші зони дотику** на мобільних (кнопки, чекбокси) та зміна розміру
  чек-листа тепер працює й пальцем, не лише мишею.
- **Встановлення на головний екран.** Додаток має `manifest.json` і значок —
  на телефоні можна додати його на головний екран через меню браузера
  («Додати на головний екран» / «Install app»), і він відкриватиметься на
  весь екран, без адресного рядка.

## Запуск у Cursor

1. Відкрийте цю папку в Cursor.
2. Відкрийте вбудований термінал (`` Ctrl+` ``) і виконайте:
   ```
   npm install
   npm run dev
   ```
3. Відкрийте посилання на кшталт `http://localhost:5173`.

Для статичної збірки: `npm run build`, потім `npm run preview`.

## Структура проєкту

```
public/
  manifest.json, icon-*.png, apple-touch-icon.png, favicon-32.png
                                значок і маніфест для встановлення на телефон
src/
  lib/
    id.js, constants.js        базові константи, палітри, стадії за замовчуванням
    tree.js                    незмінні (immutable) операції над деревом WBS
    transform.js                нотатка ⇄ план/WBS в обидва боки
    layout.js                    розкладка вузлів для вигляду «Схема»
    links.js                     розбір [[посилань]], резолвінг, зворотні посилання
    docs.js                       сортування, унікальні назви, терміни/дедлайни
    useIsMobileLayout.js          хук: чи зараз активна мобільна (однопанельна) верстка
    storage.js / idb.js            IndexedDB: стан застосунку + файли (Blob)
    export.js                      захоплення DOM → PNG/PDF, друк простого тексту
  state/
    AppStateContext.jsx          весь стан (useReducer), кошик, дії, автозбереження
  components/
    Sidebar.jsx                  дерево документів, перетягування (у т.ч. категорій
                                  і групового виділення), закріплення
    Workspace.jsx                 заголовок документа: пріоритет, стадія, термін,
                                  закріплення, експорт, видалення
    NoteEditor / PlanEditor / WbsEditor / ProjectEditor
    AttachmentsPanel.jsx           файли та фото (зберігаються як Blob в IndexedDB)
    LinkPicker.jsx                 вставка посилань + інлайн-рендер посилань
    BacklinksPanel.jsx             «хто посилається на це»
    TrashModal.jsx / ReminderModal.jsx
    SettingsModal.jsx              керування стадіями розробки
```

## Що реалізовано (друга версія)

**Типи документів:** Нотатка, План (плаский список), WBS План, Проєкт (контейнер) —
кожен зі своєю іконкою скрізь в інтерфейсі.

**Пошук за назвою:** поле під кнопкою «+ Створити» у сайдбарі. Фільтрує
документи в усіх категоріях (і вкладені в проєкти) за фрагментом назви.

**WBS має 2 вигляди** (перемикач над блоками):
- **Список** — звичний ієрархічний редактор (як і раніше).
- **Схема** — читабельне орг-дерево (Project → Task → Subtask), автоматично
  побудоване з тієї самої структури блоків.

**Кошик замість підтверджень:** видалення документа/блоку/кроку/задачі більше не
питає — одразу летить у кошик з миттєвим «Скасувати» в спливному повідомленні,
або відновлення пізніше через «🗑 Кошик» у сайдбарі.

**Терміни (дедлайни):** на документі цілком і окремо на кожному кроці плану,
блоці WBS та пункті чек-листа. При запуску застосунку — спливне вікно зі
списком усього простроченого й того, що горить сьогодні.

**Посилання як в Obsidian:** кнопка 🔗 біля нотатки/кроку/блоку відкриває пошук
документа (і, за бажання, конкретного рядка в ньому). Посилання прив'язані до
внутрішнього id, тому не ламаються при перейменуванні. У нотатці є режим
«Перегляд» з клікабельними посиланнями; для кроків плану/блоків WBS резолвлена
мітка показується під полем. На кожному документі є панель «Зворотні
посилання» — хто на нього посилається.

**Файли та фото:** доступ через «⋯» у заголовку документа → «📎 Додані файли»
(окреме вікно, не займає місце в тексті документа). Підписані типом файлу
(«Зображення», «PDF», «Документ Word»...). Клік по фото відкриває його
збільшено (з кнопкою «⬇ Завантажити» всередині перегляду), клік по іншому
файлу відкриває його в новій вкладці — нічого не тягнеться на пристрій без
потреби. Зберігаються в IndexedDB (не в localStorage — той мав ліміт ~5-10 МБ).
На заблокованому паролем документі кнопка файлів взагалі не показується.

**Перетягування (для ПК):** документи між собою (зміна порядку, або занесення в
проєкт, якщо тягнути на нього), Ctrl/Cmd+клік для групового виділення й
групового перетягування, і саму бічну панель — категорії («Проєкти»,
«Нотатки»...) теж можна тягати одна повз одну. На дотик / з клавіатури —
дивіться розділ «Мобільний і сенсорний досвід» вище.

**Експорт** (кнопка «⬇ Експорт» у заголовку документа):
- 📝 **PDF з текстом (завантажити)** — справжній PDF з вибірковим текстом
  (не знімок екрана), одразу завантажується без діалогу друку. Кирилицю
  малює вбудований шрифт Liberation Sans (вільна ліцензія SIL OFL, файли
  лежать у `public/fonts/`) через пакет `@pdf-lib/fontkit`. **Найновіша й
  найменш перевірена опція** — я не мав змоги відкрити застосунок у
  живому браузері, щоб це підтвердити візуально; якщо щось не так,
  лишаються робочі варіанти нижче.
- 🎨 **PDF (як на екрані)** — знімок документа з усіма кольорами й бейджами.
- 🖼️ **Зображення (PNG)** — той самий знімок як картинка.
- 📄 **PDF (простий текст, друк)** — відкриває системний діалог друку з
  чистим чорно-білим текстом (виберіть «Зберегти як PDF»). Перевірений,
  надійний запасний варіант, якщо новий текстовий PDF вище не спрацює.

**Кнопку трансформації в нотатці** зроблено малою й неяскравою; додано
дзеркальні кнопки План → Нотатка та WBS → Нотатка.

**Чек-лист:** на ПК завжди присутній праворуч, згортається в тонку смужку або
розтягується перетягуванням лівого краю (мишею або пальцем). На телефоні —
окрема повноекранна панель, відкривається кнопкою «✅ Чек-лист» у заголовку
документа.

**Сайдбар (список документів):** на ПК можна згорнути в тонку смужку кнопкою
«◀» в шапці — більше місця під робочу область. На телефоні ця настройка не
діє: там сайдбар — окрема повноекранна панель зі своєю навігацією.

**Пароль (екран приватності, не шифрування):** можна закрити паролем окремий
документ (кнопка «🔒» у меню «...» заголовка) і/або весь застосунок (⚙️
Налаштування → «Захист застосунку»). Поруч із кнопкою пароля з'являється «🔐» —
замикає одразу, без перезавантаження сторінки (зручно, якщо треба швидко
приховати документ). **Поки документ заблокований — жодної дії з ним, крім
розблокування:** немає ні експорту, ні зміни стадії/терміну/пріоритету/назви,
ні доступу до файлів чи чек-листа цього документа (все це раніше залишалось
доступним навіть без розблокування — виправлено). Лишається тільки «Видалити
документ», як єдиний шлях, якщо забули пароль. Розблокування діє тільки в
межах поточного сеансу — застосунок і документи знову «замикаються» при
кожному новому відкритті, як екран блокування телефону. **Це не справжнє
шифрування:** пароль зберігається звичайним текстом в IndexedDB і технічно
доступний через інструменти розробника браузера. Якщо забудете пароль —
прибрати захист можна
тільки повністю, без вводу старого (сам документ не постраждає).

**Тема застосунку:** ⚙️ Налаштування → «Тема» — 🌙 Темна / ☀️ Світла. Повністю
окрема палітра кольорів (не просто інверсія), з тими самими кольорами
акценту в обох темах.

**Вигляд нотатки:** кнопка-крапка в панелі інструментів нотатки (біля «Перетворити
на») — 6 пастельних кольорів фону (молочний, пісочний, шавлієвий, небесний,
рожевий, лавандовий) з автоматично підібраним темним текстом для читабельності,
плюс **тип паперу**: Чистий / Лінія / Коса лінія / Клітинка / Крапки —
як вибір фізичного зошита. Стосується тільки нотаток — плани, WBS і проєкти
лишаються стандартними.

**Область для тексту нотатки** тепер автоматично заповнює всю вільну висоту
екрана — раніше була фіксована невелика висота, яку доводилось розтягувати
вручну.

**Колір акценту:** ⚙️ Налаштування → «Колір акценту» — 10 готових кольорів або
«Типовий», щоб повернути початковий червоний. Змінює кнопки, виділення,
фокус-рамку та значок WBS по всьому застосунку одразу.

**Стадії розробки:** повністю кастомні (⚙️ «Стадії розробки»), призначаються
документу, кроку плану чи блоку WBS. Окремо — кольорові мітки пріоритету на
самих документах, видно в сайдбарі без відкриття.

## Важливі нотатки про дані

- Все локально, в IndexedDB браузера (без сервера, без інтернету).
- Якщо ви користувались попередньою версією (localStorage) — дані автоматично
  перенесуться в IndexedDB при першому запуску цієї версії.
- Очищення даних сайту в браузері видаляє все, включно з файлами.
